# ACS 3420 - iOS Game Development

## Course Description

An introduction to gaming on mobile devices, delivered as a self-paced independent study. You'll learn SpriteKit and the core concepts that show up in most mobile games: sprites, actions, collisions, physics, scene management, and software architecture. By the end of the course you'll have designed, built, and playtested an original iOS game.

## Who This Is For

This course assumes you already have an introductory understanding of Swift and iOS development — comfortable with the language basics (optionals, classes, closures) and have built at least a simple app in Xcode with UIKit or SwiftUI. No prior game development or SpriteKit experience is assumed.

## Course Format

**Delivery**: Self-paced independent study
**Estimated effort**: 75 total hours (~9-10 weeks at 8 hours/week, adjust to your own pace)
**Prerequisite**: Xcode installed, working knowledge of Swift and basic iOS app development

There are no live class sessions. Each lesson is a standalone markdown document you work through on your own, with hands-on checkpoints along the way. If you're doing this course under an advisor or mentor, agree on a check-in cadence (e.g., weekly) to review progress and unblock questions — the pacing below is a starting suggestion, not a fixed schedule.

## Learning Outcomes

By the end of the course, you will be able to:

1. Build game projects using Xcode, Swift, and SpriteKit.
2. Identify trade-offs of different game architectures and select the best fit for a game.
3. Execute testing and debugging strategies specific to iOS games.
4. Integrate native game engines (SceneKit, GameKit) into an iOS project.

Each lesson builds on the last — work through them in order. Lessons 1-4 build a single running project ("AstroJunk"); after that, each lesson stands more on its own.

## Self-Assessment

There's no proctored exam. To confirm you've met the learning outcomes:

- Complete each lesson's hands-on checkpoints — tracked in the [Course Checklist](Assignments/Checklist.md).
- Work through the [Study Guide](Assignments/StudyGuide.md) and honestly assess your understanding of each outcome — go back and review any lesson where you're unsure.
- Design, build, and playtest an original game that satisfies the [Final Project](Assignments/Project.md) requirements.

## What You Need to Pass

To complete this course you must:

- Check off every item in the [Course Checklist](Assignments/Checklist.md) — every lesson checkpoint, the Study Guide self-assessment, and the final project.
- Deliver a final project that meets all the requirements in [Project.md](Assignments/Project.md), including the Game Design Document, at least one user test, and 6 of the 8 required game features.

There's no attendance policy or seat-time requirement — completion is defined by the checklist, not the calendar.
